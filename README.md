# 单片机项目仓库

**MCU Project Repository**

---

> 一个存放单片机开发项目的仓库，内容供大家参考与交流，不定期更新。
>
> A repository for microcontroller (MCU) development projects — open for reference and discussion, updated from time to time.

---

## 关于本仓库

本仓库用于存放单片机相关的项目文件，包括但不限于：

- **开发板例程**：51 系列、STM32、ESP32、Arduino、树莓派 Pico 等平台的入门与进阶例程
- **外设驱动**：LCD 屏、按键矩阵、电机驱动、通信模块（UART / I2C / SPI / CAN）等常用外设的驱动代码
- **传感器应用**：温湿度、超声波、红外、陀螺仪、GPS 等传感器的数据采集与处理示例
- **项目实战**：完整的综合项目，包含原理图、源码、接线说明与演示效果
- **学习笔记**：调试经验、踩坑记录、资料整理等

### About This Repository

This repository hosts microcontroller-related project files, including but not limited to:

- **Board Examples**: Getting-started and advanced examples for 8051, STM32, ESP32, Arduino, Raspberry Pi Pico, etc.
- **Peripheral Drivers**: Drivers for LCDs, keypads, motor control, and communication modules (UART / I2C / SPI / CAN), etc.
- **Sensor Applications**: Data acquisition and processing examples for temperature/humidity, ultrasonic, infrared, gyroscope, GPS sensors, etc.
- **Practical Projects**: Complete projects with schematics, source code, wiring instructions, and demos.
- **Study Notes**: Debugging experience, pitfalls, and collected references.
