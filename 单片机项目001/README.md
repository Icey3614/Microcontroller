# 🖥️ 桌面多功能智能摆件 — 51单片机综合项目

基于 **STC89C52RC / AT89C52** 的桌面多功能智能摆件，集成 LCD1602 显示、矩阵键盘交互、温度传感器、音乐播放、串口通信、计算器等功能。

> **开发环境**: Keil uVision5 (C51) + Proteus 8 Professional

---

## ✨ 功能矩阵

| 功能 | 说明 |
|------|------|
| 🔐 开机密码锁 | 3位密码验证（默认`123`），安全开机 |
| 🌡️ 温度监测 | DS18B20 采集，精度 0.1℃，超 40℃ 蜂鸣器长鸣报警 |
| ⏱️ 系统计时器 | 密码验证通过后，精确累计运行时间（时:分:秒） |
| 🎵 音乐播放器 | 非阻塞播放《青花瓷》，Timer1 动态频率生成 |
| 🧮 定点计算器 | 16 键矩阵键盘，加减乘除，结果保留 2 位小数 |
| 📡 串口通信 | UART 9600bps，流式接收上位机 ASCII 字符并实时显示 |
| 💡 环境亮度 | XPT2046 ADC 采集光敏电阻值，0-9999 量化显示 |
| 🔄 手动切页 | K3/K4 独立按键循环切页，K2 长按 1 秒安全退出 |

## 🔌 硬件拓扑

| 模块 | 接口/引脚 | 备注 |
|------|----------|------|
| MCU | STC89C52RC / AT89C52 | 12T 模式，11.0592MHz 晶振 |
| 显示 | LCD1602 (P0 并行数据，P2.5 EN) | 与蜂鸣器共用 P2.5 |
| 温度 | DS18B20 (P3.7 单总线) | 与 XPT2046 DOUT 复用 P3.7 |
| ADC | XPT2046 (SPI: P3.5 CS) | 4线 SPI |
| 按键 | 4 独立按键 (P3.0~P3.3) | K1~K4 |
| 矩阵 | 4×4 矩阵键盘 (P1 端口) | S1~S16 |
| 蜂鸣器 | 无源蜂鸣器 (P2.5) | 与 LCD_EN 复用 |
| 串口 | UART (P3.0 RXD, P3.1 TXD) | 9600bps |

> ⚠️ **引脚复用警告**: P2.5、P3.5、P3.7 存在多外设共用，驱动层已实现分时片选与电平锁定隔离。

## 🚀 快速上手

### 1. 克隆仓库

```bash
git clone <your-repo-url>
```

### 2. 配置 Git LFS（二进制文件管理）

```bash
git lfs install
```

### 3. 打开 Keil 工程

用 Keil uVision5 打开对应目录下的 `terminal.uvproj`：
- `代码部分_实验板/` — 真实开发板
- `代码部分_虚拟板/` — Proteus 仿真
- `代码部分_实验板_带注释/` — 教学版

### 4. Proteus 仿真

用 Proteus 8 打开 `两种Proteus搭建工程/` 下的 `期末仿真.pdsprj`，加载对应 `terminal.hex` 即可运行。

## 🔑 操作说明

| 按键 | 功能 |
|------|------|
| K1 长按 3 秒 | 开机 / 关机 |
| K2 长按 1 秒 | 从任意功能退回主菜单 |
| K3 单击 | 主菜单向左循环切页 |
| K4 单击 | 主菜单向右循环切页 |
| 矩阵 1~6 | 在主菜单直接进入对应功能 |
