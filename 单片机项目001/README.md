# 🖥️ 桌面多功能智能摆件 — 51单片机综合项目

基于 **STC89C52RC / AT89C52** 的桌面多功能智能摆件，集成 LCD1602 显示、矩阵键盘交互、温度传感器、音乐播放、串口通信、计算器、电子琴、倒计时、反应测试等 9 大功能。

> **开发环境**: Keil uVision5 (C51) + Proteus 8 Professional

---

## 🚀 V2.0 更新摘要

- **全整数定点化**：DS18B20 温度读取与显示改为 ×100 定点整数运算，彻底移除 Keil C51 浮点库，Flash 占用显著下降，为新增功能腾出空间。
- **LCD 增量刷新**：计算器、串口、倒计时等界面只刷新变化区域，速度更快、画面无闪烁。
- **计算器重构**：去除重复清屏重绘、合并冗余分支、数字键映射改查表；修复小数点占位显示错误。
- **菜单扩容**：由 3 页 6 功能扩展为 **5 页 9 功能**（K3/K4 循环切页，矩阵 S1~S9 直达）。
- **新增功能**：🎹 电子琴、⏳ 倒计时器、⚡ 反应速度测试。
- **仓库整理**：移除 Keil 编译产物（Listings/Objects）、Proteus 自动备份与旧固件 hex，仓库只保留源码与工程文件。

## ✨ 功能矩阵

| 功能 | 说明 |
|------|------|
| 🔐 开机密码锁 | 3位密码验证（默认`123`），安全开机 |
| 🌡️ 温度监测 | DS18B20 采集（整数定点，精度 0.01℃），超 40℃ 蜂鸣器长鸣报警 |
| ⏱️ 系统计时器 | 密码验证通过后，精确累计运行时间（时:分:秒） |
| 🎵 音乐播放器 | 非阻塞播放《青花瓷》，Timer1 动态频率生成 |
| 🧮 定点计算器 | 16 键矩阵键盘，加减乘除，结果保留 2 位小数 |
| 📡 串口通信 | UART 9600bps，流式接收上位机 ASCII 字符并实时显示 |
| 💡 环境亮度 | XPT2046 ADC 采集光敏电阻值，0-9999 量化显示 |
| 🎹 电子琴 | S1~S16 对应 16 个音阶，按下发声，250ms 自动停音 |
| ⏳ 倒计时器 | 4 位数字设定 MM:SS，K4 启停、K3 清零，到点蜂鸣长鸣 |
| ⚡ 反应测试 | 随机延时后显示 GO，按键测量反应毫秒数 |
| 🔄 手动切页 | K3/K4 独立按键循环切页（5 页），K2 长按 1 秒安全退出 |

## 🔌 硬件拓扑

| 模块 | 接口/引脚 | 备注 |
|------|----------|------|
| MCU | STC89C52RC / AT89C52 | 12T 模式，11.0592MHz 晶振 |
| 显示 | LCD1602 (P0 并行数据，P2.5 EN) | 与蜂鸣器共用 P2.5 |
| 温度 | DS18B20 (P3.7 单总线) | 与 XPT2046 DOUT 复用 P3.7 |
| ADC | XPT2046 (SPI: P3.5 CS) | 4线 SPI |
| 按键 | 4 独立按键 (P3.0~P3.3) | K1~K4 |
| 矩阵 | 4×4 矩阵键盘 (P1 端口) | S1~S16 |
| 蜂鸣器 | 无源蜂鸣器 (P2.5) | 与 LCD_EN 复用 |
| 串口 | UART (P3.0 RXD, P3.1 TXD) | 9600bps |

> ⚠️ **引脚复用警告**: P2.5、P3.5、P3.7 存在多外设共用，驱动层已实现分时片选与电平锁定隔离。

## 🚀 快速上手

### 1. 克隆仓库

```bash
git clone <your-repo-url>
```

### 2. 配置 Git LFS（二进制文件管理）

```bash
git lfs install
```

### 3. 打开 Keil 工程

用 Keil uVision5 打开对应目录下的 `terminal.uvproj`：
- `代码部分_实验板/` — 真实开发板
- `代码部分_虚拟板/` — Proteus 仿真
- `代码部分_实验板_带注释/` — 教学版

### 4. Proteus 仿真

先用 Keil 编译 `代码部分_虚拟板/terminal.uvproj`，把生成的 `terminal.hex` 复制到对应的 `51单片机仿真/` 目录；
再用 Proteus 8 打开 `两种Proteus搭建工程/` 下的 `综合仿真.pdsprj`，为单片机加载该 `terminal.hex` 即可运行。

> 💡 `terminal.hex` 属于编译产物，仓库中不保存；每次代码修改后需重新编译生成。

## 🔑 操作说明

| 按键 | 功能 |
|------|------|
| K1 长按 3 秒 | 开机 / 关机 |
| K2 长按 1 秒 | 从任意功能退回主菜单 |
| K3 单击 | 主菜单向左循环切页 |
| K4 单击 | 主菜单向右循环切页 |
| 矩阵 1~9 | 在主菜单直接进入对应功能 |
| 倒计时内 K4 | 开始 / 暂停倒计时 |
| 倒计时内 K3 | 清零重新设定 |
| 反应测试内 K4 | 开始测试 / 重玩一次 |
